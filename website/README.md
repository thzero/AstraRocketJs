# Website

The AstraRocketJs user guide, built with [Docusaurus](https://docusaurus.io/).

```bash
npm install
npm start      # build both languages and serve them
npm run dev    # English only, with hot reload
```

See the Documentation section of [CONTRIBUTING.md](../CONTRIBUTING.md) for writing and translating pages. The site is published with the app by the Pages deploy, `.github/workflows/deploy.yml`.
