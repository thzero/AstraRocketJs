AstraRockettoOnshape

An easy two-step process to create Onshape models from AstraRocket designs. Sizes, positions and masses come from the OpenRocket engine that simulates the design, so the Onshape document matches the rocket that flies.

  1. In AstraRocket, choose Menu → Export → JSON
  2. Use the "AstraRocketOnshapeImport" custom feature and select the .json after importing

Step-by-step help: AstraRocket online help, Exporting JSON for Onshape

AstraRocket
In Onshape
  1. Create a new document or open an existing one.
  2. Create a new Part Studio.
  3. If the document does not have it yet, add a custom feature and search for AstraRocketOnshapeImport.
  4. Import the downloaded .json file into the document.
  5. Open the AstraRocketOnshapeImport feature and select the JSON file.
