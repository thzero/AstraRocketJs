# Contributing to AstraRocketJs 🚀

Thanks for your interest in contributing! 😊 Code, bug reports, feature ideas, translations, and docs are all welcome.

## 📖 The full contributing guide lives in the Wiki

**→ See the [**Wiki → Contributing**](https://github.com/thzero/AstraRocketJs/wiki/Contributing) page.** It covers reporting bugs, suggesting features, the development setup (install, run, engine rebuild), the catalog tools, commit etiquette, pull requests, translation, and maintainer tasks.

By participating you agree to our [Code of Conduct](CODE_OF_CONDUCT.md).

## Quick start

- **Report a bug or request a feature** — open a [GitHub issue](https://github.com/thzero/AstraRocketJs/issues/new/choose); the bug and feature-request templates will guide you.

- **Set up and run the app** — see [Wiki → Contributing → Getting started](https://github.com/thzero/AstraRocketJs/wiki/Contributing#getting-started).

- **Contribute code** — collaborators can submit a pull request via GitHub.

Everything else — engine rebuilds, catalog tools, tests, and the [Architecture & internals](https://github.com/thzero/AstraRocketJs/wiki/Architecture) deep dive — is in the [Wiki](https://github.com/thzero/AstraRocketJs/wiki).
